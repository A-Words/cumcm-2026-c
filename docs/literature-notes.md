## 元数据整理细节

- `xiao2019mpc` 的网页引用行将孙久严后的单位上标 `2` 混入了姓名。根据同页作者信息、作者简介和英文作者列表，书目采用姓名“孙久严”，不保留上标。
- Wytock 等的页码直接从作者 PDF 首页与末页核对；不额外填写仅从二次索引获得、未通过本次原始来源核实的 DOI。
- 中文作者列表完整保存在 BibTeX 中，正文参考文献样式可按篇幅规范显示“等”；没有将单位、通信作者标记或网页模板变量写入作者字段。
- SciPy 引用保留稳定官方 URL 和访问日期，不把访问日期伪作软件文档首次发表日期。
- SciPy 使用 `@online` 电子资源类型，省略无法核实的发布年份，保留 `urldate=2026-09-10`。已用本机 `bibtex8 --8bit` 和 `gbt7714-numeric` 实际生成书目，显示为 `[EB/OL]` 和访问日期，无缺年份警告，不需要补写推测年份。

## 书目构建兼容性

本机 `bibtex --version` 可以运行，但实际读取主文 `.aux` 时没有生成有效 `.bbl` 或 `.blg`。主构建曾返回 Windows 异常码 `3221226356`；在项目 `tmp` 下复制 `.aux`、`.bib` 与样式作隔离复测，仍留下零字节文件。没有因此改动全局 MiKTeX 设置或安装其他软件。

现有 `bibtex8 --8bit` 能正确读取 UTF-8 中文书目并生成全部七条引用。旧样式名 `gbt7714-numerical` 有弃用警告；使用本机同包中的 `gbt7714-numeric` 后，连同 SciPy 的 `@online` 类型，书目命令正常退出且无警告。实际输出已检查三组中文姓名，均正确显示前三位作者及“等”。

`@unpublished` 保留了 Perez-Pineiro 等作者手稿的元数据身份；当前样式默认不显示 `note` 字段，因此在完整真实题名后附加明确的 `[Manuscript]` 类型提示，避免成品书目遗漏其“作者手稿”身份。该方括号内容是类型说明，不是原论文题名的一部分。
