# 第二轮评审后的补充实验计划

本计划在新增实验运行前固定。评审对象 `5f7015c` 已通过第二轮复审；本轮补充价格感知执行层的经济基准及跨月份检验，不将已经关闭的意见重新包装为错误。

1. **保持已交付主方案。** 原四问的参数、结果表和 Excel 保持为第一轮修订的主方案。新增控制器与评估作为独立基准，不根据再次查看全年费用的结果替换主策略。
2. **价格感知反馈。** 使用确定性滚动 LP，固定已承诺的常规购电，以相同已发布净负荷预测及价格预测安排当日至午夜的储能，最小化预测紧急电费；每段仅执行首动作。当前段可用已实现负荷、光伏及当期电价，未来真值不可用。紧急电只补当前正缺口，不用于充电；充电只取常规购电与光伏余量。终端只保留物理下界1200，终端库存价值取0，不进行全年寻优。日内负荷/PV预测仍只按原策略允许的发布时间更新。规划层保持原规则，每次重规划读取各自真实库存，故总费差包含后续计划变化，不是假设两方案全年购电路径相同的纯执行费用差。
3. **公平起点。** 四种价格/调整策略分别比较原贪心反馈与价格感知反馈。1月均执行原主策略的固定贪心热启动，2月1日才更换反馈。保存全年路径，报告2—12月费用、紧急电及首末库存。价格感知基准即使变差也须完整报告；确定性LP的局部目标不能保证不确定全年费用降低。
4. **跨月滚动选择。** 对问题3、4-3的既有贪心执行层，固定五权重与六分位候选。从4月至12月，每个月开始前只用紧邻上一完整月的费用选择权重/分位，在下一月冻结。每个评分月的所有候选从已交付固定主策略在该月初的同一真实库存开始，逐日因果回放；候选末库存同时保存，不进行虚构的库存重置或退款。正式三条路径分别为1月所选固定参数、按上月选参的融合族、按上月选参的纯历史族。三条路径在4月1日共享主策略库存，此后各自跨月连续承接，绝不每月重置到参考轨迹。
5. **结果解释。** 以4—12月连续现金费用为主要指标，分月差额、首末SOC和最差月份用于描述稳定性。相邻月份不是独立样本，不据九个月结果宣称独立同分布显著性。候选族和检验协议已经看到2025年，因此这是回顾式滚动跨月评估，不能被称为真正独立的新年度验证。
6. **外部验证接口。** 同步提供冻结模型的未来数据入口：仅接收历史末日之后连续的实际量、价格及按相同发布时间提供的小时预报；当前光伏锚点由已完成观测重建。独立外部模式沿用现有固定参数，不再调参，延续各自历史真实库存。当前没有未见过的新年度数据，故只交付可运行协议和输入验证，不编造外部实证；数据此前是否被开发者见过也不能由日期自动证明。
