# 三线表样式与数据保留核查

## 目标与原始依据

本轮按用户要求，将论文中的表格尽量统一为指定 CUMCMThesis 示例的“标准三线表格”：保持正文大小，不通过缩小字体挤入宽表，不在表下另加小字说明。该要求只调整论文呈现，不改变模型、计算结果或前两轮评审修订。

参考的原始来源如下；一般排版建议与本项目采用的具体尺寸分开记录。

| 来源 | 核实位置与支持范围 |
| --- | --- |
| [CUMCMThesis 固定提交的标准三线表示例](https://github.com/latexstudio/CUMCMThesis/blob/38d1f216bec3c9ffffb7dd09bf6b6c54f486b130/example.tex#L291-L325) | 示例显式采用顶线、底线 `1.5pt` 和中线 `1pt`，表题在上，表体没有缩小字体命令。该数值是指定模板的示例设置，不是所有三线表必须采用的唯一标准。 |
| [同版本类文件的正文及表格设置](https://github.com/latexstudio/CUMCMThesis/blob/38d1f216bec3c9ffffb7dd09bf6b6c54f486b130/cumcmthesis.cls#L143-L165)及[表题设置](https://github.com/latexstudio/CUMCMThesis/blob/38d1f216bec3c9ffffb7dd09bf6b6c54f486b130/cumcmthesis.cls#L201-L214) | `\normalsize` 为 `12.05pt`，类文件为 `tabular` 设置 `\arraystretch=1.38`；原表题为宋体、小四、粗体。类文件保持原样。 |
| [booktabs 官方手册](https://ctan.math.illinois.edu/macros/latex/contrib/booktabs/booktabs.pdf) | 第 3—5 页建议不用竖线、双线，单位放在列标题，必要的分组留白可用 `\addlinespace`；第 10 页给出的默认粗线、中线、短横线宽为 `.08em`、`.05em`、`.03em`，允许调整。它不要求某个统一正文字号，也不普遍禁止表下注释。 |
| [longtable 官方手册](https://ctan.math.illinois.edu/macros/latex/required/tools/longtable.pdf) | 第 4—5 页说明 `\endfirsthead`、`\endhead`、`\endfoot`、`\endlastfoot` 对首页、续页表头及页脚的控制。本文据此重复续表表头；每页采用三线，是本次统一样式的选择。 |

“不缩小字体”和“无表下小字说明”来自用户的明确要求，不把它们冒称为 booktabs 的强制规定。

## 本文采用的设置

| 项目 | 当前实现及理由 |
| --- | --- |
| 表体与表题 | 表体使用 `\normalsize`，即模板正文的 `12.05pt`。表题统一为正文大小、粗体，并置于表格上方；不以 `\small`、`\footnotesize`、`\scriptsize` 或整体缩放压缩宽表。 |
| 线宽 | `paper/main.tex` 设置 `\heavyrulewidth=1.5pt`、`\lightrulewidth=1pt`，让无可选参数的 `\toprule`、`\midrule`、`\bottomrule` 对齐模板示例。 |
| 列边留白 | `\tabcolsep=6pt`，这里指普通列左右两侧各自的留白，并非两列文字间总距离固定为 `6pt`。不靠逐表压缩列距适配宽度。 |
| 行距 | `\arraystretch=1.38`。模板对 `tabular` 的包装不直接覆盖 `longtable`，故长表也局部显式设置相同值。 |
| 横竖线与日期分组 | 不画竖线、双线或逐行网格。日期块用加粗日期与 `\addlinespace` 区分，避免为每个日期再插一条中线。 |
| 跨页表 | 用 `longtable` 的首页、续页表头重复顶线、列标题和中线；页脚重复底线。续表标识保持正常字号。日期块尽量完整，不能出现只有续表头、没有数据的尾页。 |

购电明细原先横向铺开的六个时段改为按日期分组、每个时段一行；日内调整方案保留“原计划购电量”和“最终常规购电量”两列。全天电量、全天常规购电费仍是正常字号的数据行。紧急购电改为按日期和事件逐行列示，保留事件起止时间、电量及全天合计，不将多个事件塞入一个很宽的单元格。

原表下的小字说明全部迁入相邻正文或附录导语，覆盖购电与调整口径、常规费与紧急费的区别、储能首末时刻、事件合并容差、舍入和月度费用差额的定义。必要单位保留在表题或列标题中；解释的位置改变，不删除可比性边界。

## 数量与独立数据核验

当前论文实际输入 **31 张表**。另外两份生成模块 `hourly-marginals.tex`、`jan-history-selection.tex` 未被主文输入；它们仍随生成器统一排版并纳入保留核查，因此全模块计数为 **33 张表**，不能把 33 当作 PDF 中的实际表数。

独立保留核查以提交 `312a9fa6d477810ba082531c04970543c611be38` 的表格为基准，差异列表为空。[逐表验收记录](../paper/table-style-validation.json) 保存基准提交、各表所在页、字段检查数和源文件 SHA-256。工作区临时明细为 `tmp/pdfs/table-layout-comparison.json`，比较快照 SHA-256 为 `c8a5352d6e2dc05c48e9754364e85c0a66f901da460d1e7ecc55cc4fff090b1f`。

## 视觉核查方法与验收边界

最终 PDF 已完成全页目视验收；对修订过程中变化的页面重新渲染并核查。检查方法如下：

1. 渲染全部页面，逐页检查表体是否与相邻正文同等大小、表题是否清楚，数值和表头有无溢出、遮挡、裁剪或异常拥挤。
2. 同时检查源码线宽设置与渲染效果；位图上的粗细观感不替代对 `1.5/1/1.5pt` 设置的核对。
3. 对每张跨页表检查第一页、续页及最后一页，确认重复表头完整、有实际数据、日期块未被不必要地拆散，没有孤立表头或空尾页。
4. 检查原小字说明迁入后的段落，尤其是表格前后的口径定义、正文引用以及小节边界；浮动表不应把下一小节首段或一个词拆成相隔大段表格的两部分。
5. 复核表号、正文引用、实际表数量，并结合构建日志检查溢出框、缺字及未解析引用。对修订涉及的页面及其相邻页重新渲染，不沿用旧候选图作为新 PDF 的验收证据。

最终页数、交付文件哈希、编译结果和实际视觉验收范围统一以 [`paper/validation.json`](../paper/validation.json) 为准，不在本记录中固定页数。PDF 中共识别出 38 个表段，114 条横线全部依次符合顶/中/底的线宽与边界要求，普通表格文字实测为约 12.005 PDF pt，与模板正文的 12.05 TeX pt 对应；数学符号的自然上下标保持数学排版字号。源码未使用缩小表格字体或整体缩放命令，也没有表下小字说明。数值保留检查和页面验收分别完成，不把其中一项替代另一项。
