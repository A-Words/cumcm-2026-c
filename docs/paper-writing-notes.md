# LaTeX 论文撰写记录

## 写作目标与依据

将已有四问模型、两轮修订和实际计算归档整理为独立可读的中文数学建模论文，正文入口为 `paper/main.tex`，交付 PDF 位于 `output/pdf/microgrid-paper.pdf`。原有 Markdown 解答、决策与评审回应继续保留。

写作前重新阅读题面和评审记录，确定三个层次：先给出题意、时间对齐、物理约束和确定性模型，再说明信息可见性与实际控制，最后用完整账单和对照实验解释收益来源。主文不以验证脚本数量代替数学或经济论证。

## 结构与取舍

1. 摘要区分问题一的确定性最优解与后续因果启发式；不把回顾式同年评估称为独立泛化。
2. 明确原计划不退款、最终净调整与逐笔交易的不同。分别报告冻结调度重计费和重新优化，避免混淆。
3. 将信息子集实验与完整重规划策略分开解释；不把 18 点新预报贡献小等同于 18 点调整无价值。
4. 价格感知反馈、跨月选参的负向结果继续保留，并交代固定参数、共同期初库存、零午夜库存价值等可比性边界。
5. 主文展示汇总和关键对照，附录完整提供四个场景、四个指定日期的购电、充放电、库存、费用与紧急事件。表格按题面要求组织，完整精度归档另行保留。
6. 使用 12 篇经过核实并在正文引用的文献，其中 6 篇为中文文献。背景分别覆盖储能调度、模型预测控制、预测组合、时序评估及线性优化，不为凑数量引入未采用的方法结论。中文期刊摘要不冒充通读全文。知网标签未能通过现有浏览器连接，改由期刊官网及作者来源核实，详见 `literature-notes.md`。
7. 按用户指定的 CUMCMThesis 示例骨架重组为问题重述、模型的假设、符号说明、问题分析、模型的建立与求解、结果分析与模型检验、模型评价与推广、总结。将原来分散在预测、调整与讨论章节的内容归位，保留原公式、模型标签及计算结论。附录给出指定日期和逐月明细；AI 工具使用说明如实记录实际参与范围。完整映射见 `template-adaptation.md`。

## 数据到论文的可复现链

`scripts/build_paper_tables.py` 读取主结果、修订实验、第二轮实验及逐段 NPZ，独立聚合后生成 `paper/generated/*.tex`。正文可通过 `\PaperValue{key}` 调用核心数值，未知键会中断编译。`table-data.json` 保存完整精度数据，`manifest.json` 保存来源、生成文件哈希和核对结果。

本次模板迁移只改论文层，不调整原模型参数，不重写原始附件、主结果归档或五份 Excel。表格改版通过生成器完成，不手工改动某个结果单元格。

## 排版与构建

采用 CUMCMThesis 的 `cumcmthesis.cls` 与 `cumcm2026.sty`，固定上游提交 `38d1f216bec3c9ffffb7dd09bf6b6c54f486b130`，原样保留模板文件；来源及 SHA-256 见 `paper/template-source.json`。主文件使用 `withoutpreface,bwprint` 选项，保留标题和摘要，完全不调用目录命令，符合用户明确给出的页面排除要求。

页面尺寸、正文行距、中文章标题和居中页码沿用模板；只为本机实际字体、公式命令、表格、引用及附录字母编号作必要适配。参考文献采用 GB/T 7714 顺序编码格式。Windows 显式映射已有宋体、黑体和楷体；其他环境保留 CTEX 的自动字体选择，尚未做跨平台实际编译。

三线表本轮统一采用模板示例的顶底线 `1.5pt`、中线 `1pt`，表体和表题保持正文 `12.05pt`，表题加粗；列边留白 `\tabcolsep=6pt`，行距系数 `\arraystretch=1.38`。购电和紧急事件宽表改为纵向明细，日期块用留白分组，长表跨页重复三线及表头。全部表下小字说明迁入正文或附录导语，不通过缩小字号适配表宽。一般建议、模板具体值与核验方法见 [`table-style-audit.md`](table-style-audit.md)。

已使用 LaTeX 插件探测并尝试编译。当前 MiKTeX 的 `latexmk` 缺少 Perl，直接 XeLaTeX 可用；普通 BibTeX 在本机出现进程崩溃，已有 `bibtex8 --8bit` 能正确处理 UTF-8 题录及中文作者。因此仓库构建脚本优先采用直接 XeLaTeX 三遍与 BibTeX8，无须安装 Perl或修改全局 TeX 配置。

```powershell
python scripts/build_paper.py
```

此命令先核对并生成表格，再编译。中间文件集中于已忽略的 `tmp/paper-build/`；每次复制当前 TeX、题录、模板和两张原图到该目录下的独立源码快照，避免编辑器自动预览产生的同名辅助文件串入正式构建。重新生成交叉引用后，只有消除溢出框、缺字和未解析引用，才复制到正式 PDF 路径。纯排版迭代可使用 `--skip-tables`。编译需要 PATH 上可用的 XeLaTeX、BibTeX8（或兼容 BibTeX），以及 CTEX、GB/T 7714、natbib 等 TeX 包。
