# 按问题拆分求解代码

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `scripts/q1.py` | 第一问的确定性优化、梯形积分对照与往返效率对照 |
| `scripts/q2.py` | 第二问的1月选参及全年日前调度 |
| `scripts/q3.py` | 第三问的光伏权重/分位联合选参、历史基准和日内调度 |
| `scripts/q4.py` | 第四问的动态电价流程，复用第二、三问算法生成4-2和4-3 |
| `scripts/model.py` | 共用的LP、因果预测、物理执行和合约结算；保留旧的 `q1_solution` 导入入口 |
| `scripts/solve_common.py` | 每次求解的缓存、选参、场景归档及单问命令行输出 |
| `scripts/solve.py` | 依次调用四问，执行完整补充实验并统一生成正式结果 |

每个题号文件均可直接执行，命令见 README。第二至四问共享同一模型实现，动态电价通过显式参数传入，避免复制后出现约束或结算口径不一致。

单问结果保存在 `outputs/questions/<题号>/`，包含 `dispatch.npz` 和 `summary.json`；第三、四问另保存 `revision-dispatch.npz`。使用 `--output` 可更改目录。这些文件供单问分析，正式Excel仍从总入口生成的 `outputs/main/results.json` 导出。

本次仅改变代码组织，不改变候选参数、信息可用时点、热启动、SOC承接、求解器选项或费用公式。完整实验仍位于总入口，单问运行不会自动重算全部消融及敏感性实验。
