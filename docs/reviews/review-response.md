## 1. 预报价值归因：接受并改写论证

原文关闭某个发布时间时，同时关闭了读取新光伏预报、利用当前 SOC 重规划、负载修正和提前调整常规购电。因此“全更新相较仅 00 点节省 911,252.36 元”只是一组完整策略差，不能归因于新小时预报。

前轮独立核对得到下列原策略结果。这些数值用于说明原论证为何不成立，并非修订后主策略结果：

| 原策略对照 | 2—12 月总费用 / 元 |
| --- | ---: |
| 仅 00 点规划，没有日内调整 | 14,422,460.48 |
| 保留全部日内调整、当前观测和负载修正，仅沿用 00 点小时预报 | 13,580,285.75 |
| 原纯附件 3 策略，采用各次新小时预报 | 13,511,208.12 |
| 保留全部调整，仅 18 点沿用 12 点小时预报 | 13,511,207.99 |

保持当前光伏观测锚点一致后，仅使用 00 点小时预报仍保留原节省的 92.42%。沿“先恢复调整及观测，再加入新小时预报”的比较顺序，新小时预报对应费用差约 69,077.63 元；这不是与加入顺序无关的唯一贡献分配。18 点的约 0.13 元差异不支持经济价值断言。

修订明确区分“重规划机会”“规划器读取真实 SOC”“负载水平修正”“当前光伏观测锚点”“新发布的未来整点光伏预测值”五个概念。累计实验首先联合恢复重规划机会与实际 SOC，然后逐一控制负载修正、观测锚点和新小时预报；没有把第一步的费用差拆成纯机会和纯 SOC 贡献。严格预报对照固定三次重规划、真实 SOC、负载修正及当前锚点，按同一未来目标时刻替换可用的旧小时预报，并为替代预测器重建仅含过去日期的残差池。各次新预报的对照保留该时刻的调整机会，之后发布时间仍恢复各自允许的信息。

累计加入信息的费用差明确标为依赖顺序的策略差；逐次撤去新预报的费用差明确标为以其余信息为条件的边际差。它们不可相加冒充唯一贡献分解，也没有统计显著性保证。模拟每段实际执行始终使用真实当前净负荷和物理状态；每次允许重规划时都读取自身真实 SOC。不同策略可以形成不同库存轨迹，不把电池真实库存改成预测值或人为固定成另一策略的状态。

## 2. 缺少简单基准：接受并补入候选族

前轮在相同三次调整、负载修正、反馈、合约和 1 月六分位选择规则下，历史光伏基准选中 0.65，正式期费用为 13,428,215.91 元，比原纯附件 3 策略少 82,992.21 元。其紧急电更多，但已经按五倍电价计入总费用；题目没有另外给紧急购电量约束，因此不能以紧急量较多否定其费用优势。

修订保留纯附件 3 和纯历史光伏的可实施基准，并增加

$$\widehat V^{(\lambda)}=(1-\lambda)\widehat V^{\rm hist}+\lambda\widehat V^{\rm att3},\qquad
\lambda\in\{0,0.25,0.5,0.75,1\}.$$

每个权重均与原六个风险分位候选组合，在 1 月 15—31 日选取费用最低的组合；问题 3 和问题 4-3 分别选择。历史光伏基准在正式期只需历史实际光伏，日内使用自身真实 SOC，负载修正和调度机会与主方案遵循同样规则。为完整复现前轮历史反例，保留 1 月使用自身预测器和固定 0.8 分位的版本；同时新增“共同热启动”版本，在 1 月与新主策略一样使用纯附件 3、0.8 分位和三次更新，2 月才切换历史光伏。正式经济性比较重点使用后者，使评价期初库存一致。比较同时列总费用、紧急购电及首末库存，不将信息更多视为自动更优。

**验证边界没有被重算消除：** 只在 1 月选权重和分位，说明这些数值没有直接按 2—12 月费用搜索；但融合模型族本身是在看到评审的全年反例后提出的。因此修订属于同年数据再分析，不是新的外部测试、独立前瞻验证或多年优势证明。正式热启动的固定参数与选择后的生效日期需区分，不能把月底选中的参数倒灌给 1 月。

## 3. 免费撤回增购：接受风险，分开重计费与重优化

原主模型按最终交付量相对 00 点原计划结算，先前未交付的增购可再次修改，没有逐笔交易路径费用。这是已披露但未充分检验的实质性合约假设；不能只检查公式和余额自洽就认为已经由题面确认。

前轮冻结原调度、按“每次上调 1.5 倍、下调另付 0.5 倍且不退款”逐笔重计，问题 3 增加 395,916.19 元，问题 4-3 增加 414,377.84 元；相对各自无调整方案仅剩约 1,051.64 元和 3,103.11 元费用差。这是费用压力测试，不能称作逐笔合约下的优化结果。

修订报告明确区分三种结果：

| 结果类型 | 调度如何得到 | 适用解释 |
| --- | --- | --- |
| 主结果 | 最终净调整合约下规划并执行 | 未交付增购是可撤回申报，结算不依赖修订路径 |
| 冻结主调度逐笔重计 | 固定主策略全部动作，仅重算账单 | 检查原调度暴露于替代合约的费用风险 |
| 逐笔合约重新优化 | 每次以此前已成交版本作为基准，重选参数并重新回测 | 增购已成交、后续不退款，交易路径进入费用 |

不退款且允许不接收已付电量时，逐笔下调同样受“保持数量并不接收多余电”的方案支配。因此重新优化可限制修订量不低于上一版本；对主合约只限制不低于 00 点计划。后者可以撤回此前增购，前者不可以。这一约束差异必须进入计划器，不能仅在末尾给同一条调度换账单。

逐笔合约重新优化仍属于本文有限参数族与显式反馈下的可行策略，不是替代合约的随机全局最优。退款敏感性与逐笔收费检验分别报告，它们改变的是不同条款，不能互相替代。

## 4. 贪心反馈价格不敏感：保留局限，不冒称修复

评审给出的两段反例成立：同样的末库存，低价时紧急买电并留电给高价段，可能比“有缺口立即放电”更便宜。这说明当前反馈一般没有经济最优性。

本次修订没有将控制器改造成价格感知 MPC。保留相同反馈有利于隔离预报和合约改动；正式论文补入反例及影响，清楚区分安全可行性、结算自洽和经济最优性。若进一步更换控制器，需要另行设计可用信息一致的价格感知基准、因果回测及独立验证，不能拿确定性先知反例中的节省率直接替代全年结果。

第 1 问 35,126.948589 元的最优费用经独立 LP/MILP 核对仍成立。供电平衡、SOC 动态、功率、互斥、跨日连续和主结算自洽均可单独验证；这些检查不回答预报有无增量价值，也不证明主合约是题意唯一解释。
