# 评审后修订口径

本轮针对已核实的评审问题修复模型与论证，保留原始题目及附件。此前提交 `89111b2` 可用于复核旧结果。

## 在新实验前固定的选择

1. **分开比较重规划与预报信息。** 原来的八种 `issues` 组合仅用于说明完整重规划策略的效果。新增逐层对照：无日内重规划；开放重规划并使用真实 SOC，但沿用日前负荷/PV；增加已观测负荷修正；增加当前 PV 观测锚点；增加日内新小时预报。该分解依赖干预顺序，SOC 使用各方案自己的真实状态，不能声称各时刻 SOC 数值相同。
2. **严格控制小时预报信息。** 保持三次调整、负载修正、当前 PV 锚点及相同参数，枚举 06/12/18 新小时预报的八种启用组合。关闭一次新预报时，沿用此前最近一次允许发布的预报，按相同绝对目标小时提取。各预测器重新生成自身历史残差，禁止使用当日及未来残差。
3. **补充并比较简单基准。** 保留原纯附件 3 策略、只用历史光伏但允许三次调整的策略。新主策略考虑历史与附件 3 线性融合，附件 3 权重候选固定为 `{0, 0.25, 0.5, 0.75, 1}`，风险分位固定为既有六个候选 `{0.5, 0.65, 0.7, 0.8, 0.9, 0.95}`，仅按 1 月 15—31 日费用选择。允许选中 0，表示经过比较后忽略新增预报；不能为了让附件 3 显得有用而排除这个基准。
4. **如实说明再分析边界。** 新模型族是在审查同一年结果后提出的，因此属于同年修订分析，即使参数只用 1 月，也不称为新外部样本验证。候选以固定候选参数回放 1 月；新主策略及逐笔合约重优化的实际 1 月执行预先固定的纯附件 3 预测、0.8 分位，选中权重与分位从 2 月才生效。原纯附件/历史基准及 legacy 信息对照保留原先自身预测器热启动，用于复现评审；另补共同热启动的历史基准，保证新主策略的模型比较具有相同评价期初库存。历史误差依旧由各候选当时可计算的预测重建，不受电池动作影响。问题 2/4-2 和问题 1 保留原方法。
5. **重新优化逐笔交易合约。** 原主合约 `final_net` 是交付前计划可修订、按最终量相对 00 点计划结算。另建立 `per_revision`，每笔修订以上一版承诺为基准，上调收 1.5 倍、下调另收 0.5 倍且旧支出不退。允许放弃已付费电量时下调受支配，故该合约下重优化要求承诺只增不减。每次追加费用分别记录、最后求和。原轨迹按新规则的冻结重计费与新合约下重优化必须分列，不能相互替代。
6. **有限修复范围。** 当前贪心反馈缺乏价格分配最优性，保留其已披露局限。本轮不把它扩展或宣传成完整情景 MPC。核心工作是修复信息贡献、基准不足和合约敏感性，避免靠更换术语掩盖缺口。
