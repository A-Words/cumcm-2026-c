\section{问题分析}
\subsection{预测、购电计划与实时执行的分工}
问题一是确定性资源配置问题，可以直接建立线性规划。问题二至四同时涉及预测和控制：即使某次规划在预测输入下最优，也不能据此推出有预测误差时的全年策略最优。因此本文将预测、常规购电规划和实时执行分为三个环节，分别约束信息的可用时刻、物理动作和费用核算。储能跨时间耦合又使预测误差的经济影响依赖库存及电价，故预测精度只能作为辅助指标，主要评价量应为真实结算费用。

\subsection{四个问题的递进关系}
\begin{enumerate}
  \item 问题一的预测曲线已经给定，重点是把电量平衡、储能损耗和日循环边界写成可核验的优化模型，并确认线性松弛不会改变最优购电费用。
  \item 问题二不能读取未来真实负荷和光伏，需要先构造历史预测，再用非对称购电代价确定风险修正，最后通过实时储能反馈与紧急购电实现可行运行。
  \item 问题三同时增加预报信息和日内调整机会，必须区分这两种变化的经济作用，并明确多次申报是按最终净调整还是逐笔成交结算。
  \item 问题四再加入未来价格未知这一因素，需要以因果价格预测形成计划、以实际交付价格结算，并保持与固定电价问题相同的物理约束和比较口径。
\end{enumerate}

\subsection{相关方法与本文定位}

储能调控需要在不同电价和预测误差之间分配有限库存。分时电价下光伏储能经济调度及日前、日内协调优化已有相关研究\upcite{wu2018tou,xiao2019mpc}。模型预测控制在每次获得新观测后，重新预测并优化未来时域，仅实施首个动作；确定性滚动控制与多情景鲁棒控制具有不同的不确定性处理方式\upcite{wytock2017dem}。动态电价研究也强调预测驱动的可实施策略应与全知性能参考区分\upcite{perez2023hem}。

日前、日内协调还可结合多时间尺度MPC与分布鲁棒方法，显式处理场景分布不确定性\upcite{li2024mpc}。本文采用容易核验的风险分位规划与显式储能反馈，未实现该类分布鲁棒模型，也不把经验分位解释为联合概率约束或条件风险价值。通过历史预测基准、严格预报信息对照、替代交易合约以及价格感知反馈比较，检验结论对建模选择的依赖性。
