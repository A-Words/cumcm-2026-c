# 结构、论证与表达模式

本页是从范文观察中整理的写作建议，不是比赛评分细则。C038 等编号的来源和阅读页码见 [论文笔记](paper-samples.md)。本项目具体设置见 [项目衔接](project-integration.md)。

## 1. 先选组织方式，再定章节名

| 组织方式 | 适用情况 | 范例观察 | 写作取舍 |
| --- | --- | --- | --- |
| 逐问独立成章 | 各问方法差异较大，或每问有完整的输入、模型与结果 | C038 分别写三问；C050、C155、C235 分别写四问 | 每问形成局部闭环，避免在各章重复相同预处理和算法背景 |
| 统一“建立与求解”章，下设各问 | 多问共享变量、物理关系和主要约束 | C229、C234 将各问放在统一章内 | 先给公共部分，扩展问明确引用继承内容，再列新增项 |
| 数据处理独立成章 | 多附件连接、统计口径或特殊数据结构决定后续方法 | C229 第 5 章；C228 P4 的预处理流程 | 报告处理规则与影响，不将清洗工具操作堆成教程 |
| 数据处理放入第一问 | 处理与第一问的统计描述紧密相连 | C038 P4–10；C155 P4–5 | 后续问引用处理后的数据，避免多次定义不同版本 |

可采用“摘要 → 问题重述 → 假设与符号 → 问题分析 → 建立与求解 → 结果与检验 → 评价/总结 → 文献 → 附录”的工作骨架。假设、符号和问题分析的先后顺序可随阅读依赖调整；总结也可并入评价。本项目已有确认骨架时沿用原结构。

不要按总 PDF 页数决定正文长度。例如 C126 的参考文献在 P19、附录从 P20 开始，但整份文件有 74 页；C038 的参考文献在 P45、附录从 P46 开始，共 61 页。代码附录会显著改变总页数，不能据此设定“优秀论文应写多少页”。

## 2. 标题、摘要与关键词

### 标题

两种常见组织方式是“研究对象 + 决策/分析任务”（C050、C126），以及“关键建模机制 + 研究对象 + 任务”（C038、C065）。优先让读者知道解决什么问题；仅在方法确实构成全文核心时将其写进题名。不要把全部算法缩写串入标题，也不要把“最优”作为默认修饰词。

### 摘要

多数样本在首页按问题分段给出方法与代表结果；C065 的摘要实际延续到第二页。这是样本差异，不能从中推出一页或两页的统一规定。摘要长度首先服从当前题目及提交要求。

写作时可按以下内容压缩，顺序随题目调整：

1. 用少量文字说明对象、核心难点和整体处理方式。
2. 各问交代“为解决什么 → 用何模型/机制 → 得到什么结果”。多问共享方法时可以合并，保留各问对应结果。
3. 对最关键结果给出场景、评价区间、单位和比较对象。没有数值支撑的子问可给出具体分类结论或建议，不能为整齐而编造数字。
4. 以主要检验和关键边界收束；不写“具有很强普适性”等脱离证据的评价。

可供组织句子的框架（其中槽位不是最终正文）：

> 针对〔任务〕，考虑〔数据特点/限制〕，建立〔模型〕并采用〔求解方法〕。在〔样本或评价区间〕内，得到〔带单位的结果〕；相对于〔同条件基准〕，〔指标〕变化〔幅度〕。〔检验〕支持〔限于具体条件的结论〕。

C094 P1 同时给出求解器和贪心策略的结果，并说明质量与计算速度的取舍，可借鉴“数字 + 比较解释”的组织。C234 P1、P23 保留加入关系修正后收益下降的结果，说明摘要没有必须逐问“提升”的叙事要求。上述比较结论仍是原作者报告，不是本次复算。

关键词选研究对象、关键机制和实际使用的方法，避免泛词及未采用模型。样本的关键词数只作观察，不作为配额。

## 3. 问题重述、分析、假设与符号各司其职

| 部分 | 要回答的问题 | 应保留的内容 | 优先压缩的内容 |
| --- | --- | --- | --- |
| 问题重述 | 给了什么、限制什么、要交什么？ | 决策对象、时间范围、主要限制、题面指定结果 | 长篇行业背景、照抄附件说明 |
| 问题分析 | 难在哪里，为什么这样建模？ | 数据结构、问题递进、方法与输出的关系 | 重复题面、无选择理由的算法清单 |
| 模型假设 | 哪些额外约定使问题可求解？ | 来源或理由、适用问、影响的方程及结论 | 将已知事实包装成假设、无关的理想条件 |
| 符号说明 | 数学对象是什么，单位和索引是什么？ | 公共变量、参数、状态量、集合和单位 | 只出现一次且可就地解释的算法局部记号 |

C065 P3–4 的分析依次讨论分析目标、数据特征和模型选择，并解释配对观测不足如何限制其预测方案。可借鉴这种“证据条件 → 方法取舍”的论证；不能把该篇的具体方法判断扩大到所有数据集。

C094 P3、C234 P3 用关系图表达后续问在前问基础上增加哪些条件。若文字已足够清楚，无需另画图；画图时写清输入、输出和继承关系，不用并列算法盒子代替论证。

新增假设可以在工作底稿用“假设—依据—影响—如何检验”四列记录。题面事实和作者额外假设需可区分；对交易、损耗、舍弃、测量下限等会改答案的约定，正文应显式交代。

## 4. 数据处理要为后续模型提供依据

至少交代有实质影响的处理：样本/时间粒度、附件连接键、重复和缺失判定、异常处理、单位换算，以及处理后可用数据范围。只有确实影响方法选择的统计特征才值得在正文展开。

样本提供了两种有用观察：

- C155 P4–5 先说明数据有效性和成分结构，再介绍处理；C229 P4–5 区分颜色缺失与成分近似零值，说明为什么采取不同处理。
- C228 P4 用流程图区分附件整合、数据分析和清洗。可借鉴流程分层，具体剔除规则仍需在本题中有依据。

这些篇目的处理并不相同，不能归纳出“缺失一律补零”“异常一律删除”等规则。涉及时序预测或监督学习时，写明处理参数由哪些可用数据确定；不能用事后观测悄悄改善早期决策。

## 5. 每一问的最小完整论证

### 优化与调度类

1. 明确决策变量、状态、已知输入和决策时点。
2. 给出带经济或物理解释的目标函数；说明费用、收益、损耗的统计口径。
3. 按作用解释约束，交代索引范围、单位和边界。必要时汇总为完整模型；公共约束较多时引用编号，不重复整页公式。
4. 说明求解器或算法如何实现该模型。对自定义启发式给出有用的编码、约束处理、停止条件和随机性信息；对标准求解器报告实际参数与状态，不写无关算法教材。
5. 给出策略摘要与目标值，解释关键差异，定位完整交付表。
6. 报告与主张匹配的可行性、比较或最优性证据。

C038 P10–18 展示变量、编号约束和算法分层；P21–24 连续展示方案、收益及小结。C094 P12–13 对两种情形列出模型和参数比较。可学习其组织层次，但不必复刻冗长的逐条解释或整页重复约束。

### 统计分析、预测与分类类

围绕“研究问题 → 样本与变量 → 方法前提及选择 → 估计/训练过程 → 图表结果 → 检验与解释”展开。报告实际样本量、切分方式、评价区间及指标定义；时序任务按信息可用性描述训练与评估。

C155 P18–19 将分类规则图和训练/测试指标表放在一起，P24 给出未知样本的类别结果。这样的组织能连接“模型如何判定”与“判定结果是什么”。不要从原文某次指标为 1 推出本题也应达到 100%，或省略小样本与切分条件。

### 递进问与开放建议问

后续问开头说明继承了哪些变量、方程与假设，只展开新增信息、目标或约束，并用同口径结果比较变化。

开放建议按“缺少什么数据 → 如何采集/定义 → 进入哪个变量、约束或评价 → 可能解决什么局限”组织。C235 P32–33 将库存容量、隔夜损耗与体积数据连接到拟扩展的库存关系；可借鉴这种落点，不把尚未实现的扩展计入已完成模型。

## 6. 图表组织与正文解释

先写图表需要支撑的句子，再选择图形。以下均是可选用途，不要求凑齐：

| 论证任务 | 合适的表现形式 | 范例位置 | 需要额外交代 |
| --- | --- | --- | --- |
| 多问如何递进、数据如何处理 | 依赖图或流程图 | C094 P3、C234 P3、C228 P4 | 箭头含义、各模块输入输出 |
| 资源在对象/时段间如何分配 | 热力图或简洁调度图 | C038 P21–22 | 两轴含义、色标单位、零值与缺测区别 |
| 历史与预测如何衔接 | 带边界标记的时间序列图 | C050 P17 | 观测/预测区间、单位、模型可见信息 |
| 分类规则与表现 | 决策规则图配评价表 | C155 P19 | 样本数、训练/测试划分、指标定义 |
| 输入扰动如何影响结果 | 扰动幅度与指标表/曲线 | C065 P21 | 扰动对象、尺度、重复方式、失稳区间 |
| 方案的主要代价和收益 | 同口径比较表或分解图 | C094 P13；本项目费用表 | 基准、评价区间、计费口径及初始条件 |

解释图表时采用“观察到的差异 → 数值或形态证据 → 有根据的解释 → 结论范围”。图形本身没有识别的因果关系，不用市场、行为或物理故事补成定论。

样本中也可见密集小图、截图表格和未完成图题；这些不作为排版建议。实际制作应保证轴标、单位、图例和表头在论文正常阅读尺寸下可读；不同场景比较保持可比尺度或明确说明差别。图表样式服从项目模板，不从参考 PDF 复制像素。

## 7. 检验、评价与措辞强度

检验可以就近放在对应问，也可以在统一章集中比较。C038 P42–44 单列检验，C229 P19 按各问回顾可靠性，C155 P19、P24 则就近报告分类指标和扰动结果。组织位置可变，证据内容不能省略。

| 实际证据 | 可以支持的表述 | 不能自动推出 |
| --- | --- | --- |
| 约束、守恒、结算复核通过 | 在核验输入和容差下可行/计算一致 | 经济最优、方法优于其他方案 |
| 目标随迭代稳定 | 本次搜索趋于稳定，得到当前最好可行解 | 全局最优、重复运行一定相同 |
| 两种模型结果一致 | 在当前数据上得到一致判断 | 对未知真实标签必然正确 |
| 指定切分上的误差/准确率 | 当前评价方案下的预测/分类表现 | 所有时期或总体均具同等表现 |
| 指定范围内的扰动结果 | 在这些扰动条件下相对稳定 | 任意风险下鲁棒、对所有参数不敏感 |
| 同年回顾或重新设计后的滚动比较 | 对已分析年度的补充证据 | 未见年度的独立泛化验证 |

优势采用“具体设计 → 解决的难点 → 实际证据”的写法。局限采用“具体前提/缺口 → 可能影响 → 可补充的验证”的写法。避免把“时间有限、数据不足”作为唯一缺点，也不要把增加复杂算法当成通用改进。

## 8. 正文、附录与支撑材料

正文保留主要答案、核心公式、代表方案及改变结论的对照。附录容纳完整日期/样本结果、重复结构的长表和必要推导；代码和数据按当次提交要求组织为支撑材料，正文说明复现入口。

C050 P27 按问题列支撑材料，C228 P31 使用“文件名—类型—简介”索引。可迁移为“文件/脚本—用途—对应问题—输入输出”的清单，使读者能找到依据。C126 的长附录说明代码会占很多页，不说明代码越多论文越好。

在本项目中，正文引用由归档生成的数值与表格；完整精度归档和指定 Excel 的定位不应在压缩论文时丢失。不要将本 skill 的学习笔记、工作底稿或参考 PDF 当作参赛论文附录自动并入。
